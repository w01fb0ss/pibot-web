# 8 · 连接：应用、MCP、技能和知识库

左下角的「连接」页管理 Bot 能用的外部能力，全部装在这台电脑上：

- **应用**：本机日历、本机通讯录等。
- **MCP**：MCP 服务（Model Context Protocol），给 Bot 加工具。
- **技能**：写好的做事步骤，Bot 在合适的时候按步骤做。
- **知识库**：Obsidian 库或 Notion，Bot 只读。

## 应用

![连接 · 应用](../images/zh/connections-apps.png)

「本机日历」（读取和创建日程）和「本机通讯录」（查找联系人）点「连接」即可，数据只在这台电脑上。连接后，Bot 读写日程和联系人时仍按权限审批；本机日历也能当例行任务的触发器。

## 添加菜单

点右上角「添加」：

![添加菜单](../images/zh/connections-add.png)

- **从其他 AI 工具带过来**：Pi Bot 会看看这台电脑上的 Claude Code、Codex、Cursor、pi、OpenCode 里配好的 MCP、技能和插件，只读取名字和配置，不改它们的文件，也不上传。
- **添加 MCP**：粘贴启动命令或网址。
- **从文件夹导入插件包**：选一个文件夹或压缩包。
- **从链接导入**：粘贴 GitHub 仓库或 zip 链接。
- **写一个技能**：写好步骤，选给哪些 Bot 用。
- **Notion**、**Obsidian 库**：添加知识库。

## MCP

![连接 · MCP](../images/zh/connections-mcp.png)

还没有 MCP 时，页面会提示「看看有什么」（从其他 AI 工具带过来）或「自己添加」。

带过来或添加之前会先让你看一眼，确认后才导入；来源工具的文件保持只读。需要密钥的会提示你补上。带过来后先不给 Bot 用，回列表点「给 Bot 用」选择哪些 Bot 能用。

如果 MCP 的启动命令命中高风险规则，会标为「危险命令」，请核实来源和命令再决定；导入不代表授权执行，Bot 用的时候仍要经过权限和隔离检查。

## 技能

![连接 · 技能](../images/zh/connections-skills.png)

列表显示每个技能的说明和来源（内置、随群模板带来、自添加）。点一个技能打开详情：

![技能详情](../images/zh/skill-detail.png)

- **编辑**：修改技能内容。
- **来源与版本**。
- **运行环境**：有的技能带脚本，需要 Python 或 Node。需要时点「准备运行环境」：Pi Bot 会为这个技能建一个单独的环境（Python 由 Pi Bot 管理的 uv 按需下载并校验，经你同意后才下载），之后可以「重新准备」或「删除环境」。
- **兼容性**：「检查兼容性」看这个技能能不能在 Pi Bot 里正常用。
- **谁能用**：点 Bot 头像给它用（会复制一份到那个 Bot 的技能里）；取消只是关掉它那份，不删除。

## 写一个技能

1. 「添加」›「写一个技能」。
2. 在 `SKILL.md` 里写：开头两行 `---` 之间写 `name`（技能名）和 `description`（什么时候用，Bot 据此判断），下面写步骤。每次不同的值写成 `{参数}`，默认值放在 `metadata` 下的 `pibot-params`。
3. 需要的话，「新建文件」「上传文件」「上传文件夹」给技能加脚本或资料。
4. 在「谁能用」里选 Bot（可以先不选，之后在技能详情里再给）。
5. 点「保存」。

![写一个技能](../images/zh/skill-write.png)

示例：

```markdown
---
name: 网页上线检查
description: 用户说「准备上线」「发布前检查」网页时使用
---

# 网页上线检查

## 步骤
1. 检查 {页面} 的标题、描述和 favicon 是否齐全。
2. 用 360px 和 1280px 宽度各看一遍，记录错位。
3. 检查所有链接和电话、邮箱是否可点。
4. 把结果写成清单，未通过的项排在最前。

## 注意
- 只检查和报告，用户确认前不改文件。
```

之后在聊天里说「帮我做一次上线检查」，Bot 就会按这个技能做。在 Bot 资料的「技能」标签里可以开关每个技能。

## 导入技能和插件包

用「从文件夹导入插件包」或「从链接导入」可以导入现成的技能包（兼容 Claude Code 插件格式），包括带脚本和依赖的大型技能。导入前先预览；包里有出于安全原因不能导入的链接或文件时会拒绝并说明原因。

![连接页添加菜单里的文件夹导入与链接导入入口](../images/zh/connections-add.png)

## 知识库

![连接 · 知识库](../images/zh/connections-knowledge.png)

- **添加 Obsidian 文件夹**：选一个库文件夹，只在本机读。如果这台电脑上装了 Obsidian，页面会列出找到的库（只读出文件夹路径，不读笔记内容），点「添加」即可。
- **连接 Notion**：用 Notion 账号登录，只读。

Bot 只读知识库里的内容，不会修改笔记。

## 访问令牌

右上角「访问令牌」集中管理连接用到的令牌（例如从其他工具带过来的）。

1. 打开「连接」，点右上角「访问令牌」。窗口会列出各连接使用的令牌和手动添加的令牌；还没有时显示「还没有访问令牌」。

   ![「访问令牌」管理窗口](../images/zh/connections-tokens.png)

2. 给连接补填或更换令牌时，先核对条目对应的连接，再点该条目旁的按钮。保存新值后，Pi Bot 会用它重新连接。
3. 给命令单独添加令牌时，点左下角「新建令牌」，填写名称和值。令牌加密保存在这台电脑上，保存后只能换值，不能查看原值。

   ![「新建令牌」表单](../images/zh/connections-token-form.png)

模型 API Key 在「设置 → 模型与密钥」管理，网站账号在「设置 → 权限 → 保存的账号密码」管理。

## 邮件

当前版本还没有内置邮件连接（Gmail 等），会在后续版本提供。需要邮件时，可以先把邮件内容复制给 Bot，或连接你自己的邮件 MCP 服务器。
